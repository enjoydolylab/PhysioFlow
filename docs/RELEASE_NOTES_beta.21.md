# PhysioFlow 0.6.0-beta.21

参加者画面の入力に複数選択を追加しました。

- Input typeのMultiple choiceで、表示文字と記録値を持つ選択肢を編集できます。単一選択と同じ空欄・重複検証と問題箇所への移動を使用します。
- 回答は選択肢の設定順に並ぶ文字列配列です。必須は1つ以上の選択が必要で、任意の未回答は空配列になります。
- 実画面と操作プレビューは同じ選択・検証処理を使用します。選択肢グループのタイトルとエラーを関連付けています。
- 保存・再読込・イベント・JSONL・CSVで配列を確認しました。従来の単一選択と単独チェックボックスの出力形式は維持します。

532件のテスト、ビルド、警告なしlint、実画面と全体ブラウザー回帰を確認。実行は合成テスト条件です。真人・正式機器・原刺激素材は未検証です。
