# PhysioFlow 0.6.0-beta.12 — 研究試用

beta.11 のテンプレート設定、数値入力、保存失敗、検証項目選択に加え、検証一覧でノードの問題を選択するとフロー図が対象ノードへ移動します。検索からの移動でも以前の接続選択を解除します。

遠いノードを配置した実際のComposerで、問題選択後にノードが画面内に入ることを確認しました。511項の自動試験、ビルド、lintが通過しています。日本語の編集・実験員ガイドを同梱します。旧beta.11は保持します。

真人試用、正式な機器、原映像・原時間の実験は未検証です。DBの全シナリオを本版で再実行したとは扱いません。未コミットの実装を含みます。
