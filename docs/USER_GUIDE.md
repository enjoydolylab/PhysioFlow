# 研究人员使用指南

适用：v0.6.0-beta.4 与当前开发版；下文标注的画布新交互尚未包含在已发布安装包中。先了解[业务模型](BUSINESS_WORKFLOW.md)，旧协议操作见[迁移指南](refactor/MIGRATION_GUIDE.md)。

## 1. 准备一个测试实验

安装[Windows 测试版](https://github.com/kyzzz22/physioflow-app/releases/tag/v0.6.0-beta.4)。在首页确认数据目录，用测试编号和测试素材先跑完整流程。

新建协议默认进入 Composer V2，也可选 Emotion、Stroop、Go-No-Go 模板。模板中的媒体占位需要替换；重新生成试次会改变实验材料，已有保存的 Stroop 列表不会因升级自动修正。

## 2. 编辑流程与内容

用控制连接表达执行顺序；先完成“说明 → 刺激 → 问卷 → 结束”，再增加分支或循环。

Quick 提供常用设置，Design 包含资源、变量和参与者画面，Advanced 包含开发扩展与部署。选中节点后配置内容和结束条件。定时结束、提交结束和媒体播放结束不是同一个选项，应在试运行中逐项确认。

想保持流程而只随机刺激时，使用共享刺激池；需要改变执行出口时使用随机分支。旧 Block/Trial 的排列规则属于兼容编辑器。

## 3. 自定义画面与问卷

普通画面优先用自动布局或模板；自由布局适合需要固定位置的设计。当前开发版明确区分两种模式：自动布局中拖动用于排序，自由编辑中拖动用于移动位置。切换模式会保留当前布局的元素位置，可撤销。

开发版画布操作：

- 单击选中，Shift 点击增减选中；拖动已选元素可保持多选，Esc 取消本次拖动。重叠或锁定元素可从图层列表选择。
- 单选属性面板按位置尺寸、内容、外观和高级设置分组；多选显示批量操作，对齐适用于同一容器内未锁定的定位元素。
- 位置和尺寸在 Enter 或离开输入框时应用；Esc 放弃当前输入。锁定元素的属性不可编辑，需先解锁。
- 双击文字进入编辑。选择或拖动文字本身不会改写文字内容。
- 设置屏幕分辨率后，编辑器和预览按原比例缩放；Fit 适应可用空间，缩放不改变设计坐标。旧协议未设置屏幕尺寸时保留响应式呈现。
- 在 Screen checks 中定位越界元素或配置缺失媒体，再预览确认。固定分辨率不保证不同显示器上的物理刺激尺寸一致。

详细模式和验证边界见[画布编辑说明](refactor/CANVAS_EDITING.md)。

Participant UI Preview 用于看画面；Preview run 用于实际走流程。Questionnaire 使用专用题目编辑器；SAM 用图形选项评分，导出保留数值。外部问卷的答案仍由外部服务保存。

Protocol JSON 修改需点击 Apply changes 并通过验证。非法 JSON 或缺失必需连接会报错；关闭未应用修改会要求确认。Custom HTML 支持展示，不执行任意脚本。

## 4. 保存、试运行与冻结

保存后返回项目并重新打开，确认内容与版本。试运行至少检查：显示内容、响应输入、暂停恢复、Retry/Skip、最终保存和数据导出。

新协议的版本在冻结后不可继续编辑，需要创建可编辑版本。迁移协议须先审阅迁移报告。代码验证通过不代表真人可用性已通过。

## 5. 开始与结束会话

设置参与者编号及顺序参数，确认媒体、必需设备和存储可用。恢复含设备的会话仍需重新检查连接。必需设备读取失败会暂停 Graph 会话，可处理连接后重连。

完成或失败后检查保存结果；保存失败可重试。通过 Manage sessions 复核记录与导出，Analytics 用于已有会话的查看。按[Graph 数据契约](refactor/DATA_CONTRACT_V2.md)核对原始日志、清单和质量报告；旧协议以其导出包字典为准。

## 6. 报告问题

记录应用版本、协议版本、Windows 分辨率与缩放、复现步骤、预期和实际行为。实验设计问题还应提供条件数量、重复次数、随机种子/顺序行、实际刺激分配；敏感记录按研究要求去标识化。

正式的任务评估与签收见[研究人员验收规程](refactor/USABILITY_STUDY_PROTOCOL.md)。自动布局检查与研究人员能否独立完成实验是两类证据。
