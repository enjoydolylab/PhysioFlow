# PhysioFlow 0.6.0-beta.19

参加者画面の数字入力、回答時の案内、設計中の操作確認を改善しました。

- 数字入力の上下限を画面設計器で設定できます。空欄は制限なし、0・負数・小数は値として保持します。不正な範囲から対象入力に移動できます。
- 回答エラー時に最初の問題へフォーカスを移し、修正後は案内を更新します。エラーと入力を関連付け、量表の選択状態とキーボード操作に対応しました。
- 画面プレビューに「回答を試す」「回答をリセット」と提出値の確認を追加。必須・範囲検証は実際の回答画面と共通です。回答はプレビュー内だけで保持し、実験記録を保存しません。
- LanguageProviderなしで独立して埋め込む場合、翻訳は既定の日本語に戻ります。

529件のテスト、ビルド、警告なしlint、実画面および全体ブラウザー回帰を確認しました。真人試用、正式機器、原刺激素材の結果は未検証です。
