# PhysioFlow 0.6.0-beta.25

参加者画面テンプレートの再利用と旧エディターの整理をまとめた研究試用版です。

- 有効な画面設定を5 MB以内のJSONとして読み込み・書き出しできます。テーマ、選択肢、接続、固定サイズを保持します。素材ファイルと変数定義は含みません。
- 読み込みの取消し・不正ファイル・読み込み中の編集を保護。サイズ適用を含め、一度で元に戻せます。
- 旧文字エディター・旧フロー画面と専用コードを削除しました。旧形式の計画は元の計画を保持し、新しい下書きに変換して現行エディターで編集します。
- 変換の重複送信を防止し、保存成功を確認してから完了を案内します。
- 現行エディター、実行、データ読み込み、移行、ヘルプの共有機能を保持しています。

535件のテスト、ビルド、警告なしlint、移行と多画面幅でのブラウザー回帰を確認しました。実際の利用者、正式機器、原刺激素材の検証は未完了です。
