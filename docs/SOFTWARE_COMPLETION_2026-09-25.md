# 离线软件补齐与小组汇报演示（2026-09-25）

本轮是 beta.6 之后的开发版本，公开 beta.6 安装包不包含这些新功能。

## 本轮实现

- 分组随机支持完整的有限嵌套循环与条件/随机分支，保留组内控制流。每组需单入口和单出口连接；拒绝不完整循环、不可达节点、不受控回环和跨组数据连接。
- 本地 Graph 问卷检查点保留未提交答案、当前问题、超时记录和剩余答题时间。恢复时核对问卷结构和随机种子；新的题目尝试不会沿用旧草稿。
- 修复运行操作栏的固定高度布局，允许控件换行，使暂停和恢复控件可操作。
- 新增日语小组汇报实验：30 节点、4 段明确标注的合成视频、前后半类别平衡、SAM 与 Likert 行列、两组随机顺序、2×2 嵌套循环、随机问题分支和条件追问。演示文件内置视频，另附素材绑定版。

## 验证

`npm run quality:release`：450 项测试通过，构建、Lint 和三个浏览器验收套件通过。完整输出保存在 `artifacts/software-completion-2026-09-25/quality-release.txt`。

新增回归覆盖复杂分组多种随机种子、冻结与恢复后相同访问序列、非法循环拒绝、草稿兼容性与零值、演示素材校验及两种分组顺序。

浏览器手动验收已确认：复杂分组暂停后刷新恢复并完成；两题问卷在第二题刷新后保留第一题文字与第二题零值；暂停期间定时问卷保留约 51.3 秒而非重置到 60 秒，新尝试从空白开始。独立演示包的本地服务、协议导入、素材就绪检查和视频自然结束进入量表均已验证。

## 使用和边界

演示与日语讲稿见 `examples/lab-meeting-2026-09-25/README_JA.md` 和 `GUIDE.html`。运行 `python3 scripts/package-lab-meeting-demo.py` 将当前 `dist/` 与示例打包到 `release-demo/`，包含 Python 3 本地启动器、文件哈希及开发版标记。

没有真实设备、研究室网络、PhysioDB 服务或 40 个原始视频。未声称完成这些验收或原时长约 112 分钟实验。BrainFlow Synthetic 的既有测试不等同于真实设备验收。本轮草稿恢复范围为本地 Graph 问卷，不包含认知任务试次内部状态或跨设备草稿同步。演示合成视频不代表有效的情绪诱发材料。
