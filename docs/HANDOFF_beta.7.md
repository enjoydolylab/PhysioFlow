# PhysioFlow beta.7：交接说明

研究试用候选版，2026-10-12。用于实验设计、测试运行及本地记录；真实实验和目标Windows安装仍需在使用电脑确认。

1. 解压Web包，安装Python 3。Windows打开start-windows.bat；macOS打开start-mac.command；Linux执行sh start-linux.sh。使用Chrome/Edge，勿直接打开index.html。
2. 主页选择数据文件夹。固定启动端口和浏览器，升级前备份整个数据目录。正式采集必须有可写的本地目录。
3. 导入“学術変革 experiment”设计JSON，确认210步骤。协议不包含40视频字节；在素材库按条目上传正确原视频，核对校验值。当前找到的01.mp4等文件为Git LFS指针，不可播放，不能作为原视频使用。
4. 在步骤列表编辑，图视图检查连线；先做测试运行，再冻结版本。独立管理窗口通过准备页打开，需同源同浏览器；暂停/恢复、重试/跳过原因及观察备注会进入事件记录。
5. 运行结束确认保存成功；在记录页复核并导出完整ZIP。媒体原始文件及采集电脑的原始设备录制单独备份，勿仅保留浏览器缓存。
6. 保存失败保留页面并重试；设备断连先重连，信号检查通过再恢复；媒体缺失返回设计页补文件。不要清浏览器数据或删除恢复检查点来掩盖错误。

本Web包是静态应用，未包含PF Hosted/官方PhysioDB服务端。数据库管理、官方SDK Test Run及原始录制上传需另行部署源码服务（npm run desk）并私下配置凭据；不要向参与者交付管理员令牌。BrainFlow工具随包附带，依赖与设备由采集电脑另行准备。

接收电脑试跑：启动→选择目录→导入→绑定测试媒体→编辑/撤销→测试运行→暂停/恢复→保存→复核→导出→重开读取。记录系统、浏览器、分辨率/缩放和实际结果；通过试跑不代表正式原素材或112分钟实验通过。

交接问题：记录候选版号、出错步骤、可复现操作及脱敏错误信息，交回提供本包的研究者。包内不预填私人联系方式、数据库凭据或真实参与者数据。
