# 实验自定义：本轮改进与使用路径

2026-09-12。当前优先改善实验作者的配置体验；数据库、设备团队对接与中央登录暂不作为本轮工作。

## 本轮实现

### 响应选项

在 Composer 选择 Response 节点，打开 Response 参数组。逐项填写显示标签、记录值和可选按键，使用 Add response option / Remove option 增删。旧行格式可读取，编辑后保存为结构化数组，标签可以包含逗号与等号。界面提示重复值、重复按键和空记录值；这些提示不是新的冻结校验门禁。正确答案仍在 Scoring 设置中填写，与记录值对应。

### 认知任务试次

选择 Cognitive task，配置 Task 中的范式、随机种子和 Go 比例，在 Number of trials 中填写数量，再点击生成或替换。修改数量本身不修改已保存试次。Stroop 要求 4 的倍数，选择 8 的倍数可使每种墨色的一致/不一致试次数相等；Go/No-Go 至少 10 次。本编辑入口最多生成 10,000 次。生成后可展开查看前 20 次及已保存总数。

### 媒体与随机刺激

Quick 模式现在也显示 Media library 和 Stimulus pools。上传资源、创建池、勾选池内资源，再在 Media 节点选择池即可配置刺激抽样，无需为此切换模式。池内一轮不放回抽取；耗尽后重复种子顺序。要重复执行呈现仍需设置流程循环，刺激池不会自动增加试次数。

## 后续自定义工作

### 新增：重复一段流程

选择一个呈现或响应节点，在右侧 Repeat a sequence 中选择 Repeat through（结束步骤），输入 Total repetitions。也可以 Shift 多选连续步骤。创建前显示按控制连接计算的执行顺序及“步骤数 × 总遍数”，遍数包含第一次。点击 Create repeat sequence 一次性建立 Loop、循环体回路及出口；之后选择 Loop，在 Maximum iterations 修改总遍数。操作通过原有协议变更入口提交，可使用编辑器撤销。

该快捷入口适用于单入口、单出口的连续参与者步骤，不包装分支、不包装已有重复路径。它保留数据连接和步骤配置，不自动打乱步骤顺序，也不是新增通用 Trial 模型。复杂流程继续使用原有控制节点编辑。自动化单测已验证“两步重复三遍，之后进入休息”的真实运行顺序。

继续围绕“指导语 → 重复刺激/响应 → 问卷 → 结束”完善可视化配置。下一步评估条件表与更完整的执行顺序预览；先明确循环次数、退出条件和数据归属，再决定通用 Trial 模型，不能把 Group 直接当作可执行试次。

真人易用性仍需验证：研究人员能否独立配置选项、生成指定数量试次、完成刺激池分配，并解释最终导出结果。浏览器回归不能替代该验证。
