# PhysioFlow 0.6.0-beta.11 — 研究試用

テンプレート・設定・検証の編集フローを改善しました。

- 検証一覧から対象を選択すると以前の選択を解除し、現在の選択に関係する問題だけ表示できます。
- Stroop / Go-No-Go は作成前に入力を検証し、本試行・練習試行・Go/No-Goの件数を表示します。
- 感情テンプレートの注視時間・回復時間・順序・乱数シードを作成前に設定できます。動画の追加が必要なことを案内します。
- 数値の空入力を0に変換せず、固定/待機時間の不足や不正な型を検証します。
- テンプレートの保存失敗時は設定画面と入力を保持します。

511項の自動試験、ビルド、lint、実際の編集画面・保存再読込・保存失敗・テンプレートとComposer/Hostedのブラウザ検証を実施しました。日語の編集ガイドを同梱しています。未コミットの実装を含みます。

DB機能は以前の隔離DB検証を参照してください。本版の全DBシナリオを再実行したとは扱いません。真人試用、正式な機器、原映像・原時間の実験は未検証です。旧beta.10は保持します。
