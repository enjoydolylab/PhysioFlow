## 验收方法和证据

- `npm run quality:release`：445 项 Node 测试、生产构建、零警告 Lint、三个浏览器套件。
- `npm run test:e2e:offline`：真实 Chrome 页面、真实浏览器文件句柄读写。目录选择器由测试替换为 OPFS，未验证系统原生选目录对话框。
- 原始协议结构：210 节点、40 次媒体、120 个问卷、1,080 个回答；核对全部节点、回答值、连续事件序号、素材无重复和半场类别平衡。所有视频替换为 QA 蓝色视频，等待时间缩短，**不是原时长约 112 分钟验收**。
- BrainFlow 使用实际 Python 代理及 Synthetic Board（board -1），验证错误令牌、采集、暂停恢复、代理重启、新令牌重连；浏览器预览值/时间戳逐项对照原始 JSONL，已确认 marker 对照原始数据。
- PhysioDB 使用真实本地 HTTP 测试服务：从上述 Synthetic 原始文件上传，逐项比较数值/时间戳；覆盖字段单位错配、分批部分失败、取消后停止后续批次和超时不确定写入提示。未接触研究室服务。
- Rust 原子替换及分块写入测试；Windows CI 额外运行平台专用的替换失败保护测试。

机器结果及会话证据位于 `artifacts/offline-acceptance-2026-09-24/`；以 `REPORT.json` 的 `status: passed` 和最终日志为准。完整会话、原始合成记录均标识为 QA。

复现离线测试：准备 Node/npm、Chrome（测试 harness 中可查看路径）、ffmpeg；在独立 Python 环境安装 `tools/brainflow/requirements.txt`，运行 `BRAINFLOW_PYTHON=/绝对路径/python npm run test:e2e:offline`。测试会自行启停 Vite、Chrome、Synthetic 代理和本地 HTTP 服务。
