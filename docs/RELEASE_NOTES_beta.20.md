# PhysioFlow 0.6.0-beta.20

参加者画面の入力に単一選択を追加しました。

- Input typeでSingle choiceを選び、表示文字と記録値を別々に設定できます。型を変更して戻しても選択肢を保持します。
- 選択肢は1〜1000個、表示文字と記録値は空欄不可、記録値は重複不可。問題は画面チェックから選択肢の編集へ移動できます。
- 実画面と交互プレビューは同じ必須・選択肢検証を使用します。記録値は文字列で保存し、"0"も回答として扱います。
- 既存のResponse部品では従来の自由キー・キー設定を維持します。
