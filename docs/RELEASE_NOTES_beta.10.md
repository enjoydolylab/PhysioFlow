# PhysioFlow 0.6.0-beta.10 — 研究試用

beta.9 の実行データ出力と操作結果の照会に加え、遅れて届いた一時停止・再開の操作を現在のステップと再試行回数で検証します。過去のステップへの操作は拒否します。

監視画面では実験終了後の最終保存と途中のチェックポイントを区別し、保存失敗が以前の「保存済み」に隠れないようにしました。サーバ保存を別途表示し、保存失敗時の対処を日本語で案内します。OPERATOR_GUIDE_日本語.md を同梱しています。

505 項の自動試験、ビルド、lint、ブラウザでの操作確認復旧と保存エラー案内を検証しました。DB の完全構造同期・長記録・完全回答エクスポートは同じDB実装を含む beta.9 包内で検証済みです。beta.10 で全 DB シナリオを再実行したとは扱いません。

正式な機器、原映像と原時間、実際の利用者による試用結果は未検証です。未コミットの実装を含みます。旧 beta.9 を保持します。
