# PhysioFlow 0.6.0-beta.23

参加者画面の回答フィールド確認と設定エラーの修正を改善しました。

- 回答フィールドの一覧で名前、型、必須/任意、選択肢の記録値、要確認状態を確認し、設定欄へ移動できます。ボタン動作が追加する値は一覧の対象外です。
- 空欄・重複する回答名を画面チェックから修正できます。同じ入力に複数の問題がある場合も独立して表示します。
- 名前と記録値は翻訳対象から除外し、言語切替でも原文を保持。界面の案内は日本語・中国語に対応します。
- プレビューから設定に戻る定位、変更後の一覧更新、短い画面での表示を確認しました。

533件のテスト、ビルド、警告なしlintと全体ブラウザー回帰を確認済み。真人、正式機器、原刺激素材の検証は未完了です。
