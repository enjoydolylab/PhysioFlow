# PhysioFlow 0.6.0-beta.22

参加者画面の部品ライブラリーに数値入力・単一選択・複数選択の直接追加を用意しました。

- 型を手動で変更せず、クリック・キーボード・ドラッグで有効な入力部品を追加できます。
- キャンバスとレイヤーツリーへのドロップは同じ生成規則を使用。回答名の重複を避け、各部品の選択肢は独立して保持します。
- ライブラリー項目をキーボードで操作できるボタンに変更し、日本語・中国語の説明を追加。
- レイヤーツリーへの入力追加で回答名が重複する問題を修正しました。

533件のテスト、ビルド、警告なしlint、実画面のクリック・Enter・両ドロップ先・元に戻す/やり直し、および全体ブラウザー回帰を確認。真人、正式機器、原刺激素材の検証は未完了です。
