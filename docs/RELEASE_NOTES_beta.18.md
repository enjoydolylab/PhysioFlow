# PhysioFlow 0.6.0-beta.18

条件分岐とループの比較結果を改善しました。

数値入力2と比較値"2.0"は数値として等しいと判定します。文字列入力の比較は従来の文字列比較を維持します。

大小比較では、実行時の入力と比較値を有限の数値として検証します。空値、真偽値、配列などを0として扱って分岐を選ぶことを防ぎます。不正な入力は実行失敗として記録し、入力変数や前の回答の確認を案内します。合法な0・負数・数字文字列は使用できます。

既存の実験手順でも数値変数と数字文字列の比較結果、および不正な動的値の扱いが修正されます。保存済み手順は自動で書き換えません。

527件のテスト、ビルド、警告なしlint、実際の実行画面および全体ブラウザー回帰を確認済み。実行テストは合成データであり、真人・正式機器・原刺激素材の検証は未完了です。
