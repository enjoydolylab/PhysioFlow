# PhysioFlow v0.6.0-beta.5 — 研究室候选版

本版交付“设计 → 准备 → 测试运行 → 冻结采集 → 查看与导出”的基本流程，供研究室验证。不是原始实验、真实设备或真实 PhysioDB 已全部验收的正式版本。

## 功能和修复

- SAM 三维（含 dominance）、SAM 同屏矩阵及 Likert 矩阵；刺激池前后半场类别平衡随机。
- 分组批量编辑、连续步骤重复、简单连续组随机、测试运行返回上一页和刷新恢复。
- 协议导入差异比较、取消处理、版本移除/恢复、冻结后派生草稿、导出反馈与重试入口。
- BrainFlow 代理及 PhysioDB v1 分批上传、失败反馈和超时处理。
- 修复 Hosted 参与者入口遗漏分组执行计划而无法启动的问题：按会话生成固定计划，刷新保持顺序，校验源协议和会话身份，导出保留冻结原件与独立执行图。

## 使用和升级

1. 升级前导出协议、每个会话 ZIP，并备份完整数据目录。关闭正在运行的实验再升级。
2. Windows 使用本版 x64 安装包（未签名、当前用户安装；需要 WebView2）。Web ZIP 解压后运行对应系统的启动脚本，需要 Python 3；不要直接打开 index.html。
3. Web 版建议使用 Chrome/Edge；选择数据目录后再正式采集。保持原有本地 URL 和端口，以便访问同一浏览器存储。
4. 导入协议并重新检查全部媒体。协议 JSON 不包含视频字节，跨电脑使用时同时迁移素材和数据目录。
5. 先测试运行，核对顺序及问卷，再冻结版本正式运行。完成后导出会话 ZIP，检查事件、响应和协议快照。
6. BrainFlow 代理需独立启动，见 tools/brainflow/README.md；PhysioDB 需用户自己的服务、认证及研究/实验/参与者标识。

回退：保留旧安装包和升级前的数据备份；旧 beta.4 不支持本版所有协议配置，不能直接用它运行新功能协议。回退应恢复升级前备份，避免覆盖本版新增会话。

## 未验收和范围限制

- 原始 40 视频、约 112 分钟完整实验及全量数据核对尚未完成，原始媒体未提供。
- OpenBCI/Mybeat 等真实硬件、实际同步精度、真实 PhysioDB 认证/持久化/读回/SSE 联调尚未完成。
- Windows 真机安装、125%/150% DPI 和研究人员独立操作验收待做；CI 构建不能替代这些。
- 组随机支持不重叠、单入口单出口、连续的展示/响应组；既有循环、分支等复杂组会明确拒绝，未扩展为通用 Trial 或跨被试配额。
- 所有编辑异常、问卷未提交内部进度恢复、多文件事务和生产 Hosted 运维尚未完整验收。

源码基线包含上游 ZIP c4bc635 的逐功能移植，非全量三方合并。细节见 docs/PROGRESS_REPORT_2026-09-24.md 和 artifacts/release-readiness-2026-09-23/ACCEPTANCE_STATUS.md。
