# PhysioFlow 0.6.0-beta.24

参加者画面をJSONテンプレートとして再利用できるようにしました。

- Presetsから画面テンプレートを読み込み・書き出しできます。有効な設定を対象とし、ファイルは5 MB以内です。
- テーマ、ID、動作、変数接続、選択肢と固定サイズを保持。メディアファイルと実験変数定義は含みません。
- 不正なファイル、取消し、読み込み中の編集、ツールを閉じた後の読み込みでは現在の画面を上書きしません。
- サイズ未指定のテンプレートは現在の画布サイズに合わせ、そのサイズを案内します。読み込みとサイズ適用を一度で元に戻せます。
- 読み込み後は操作プレビューで回答を確認できます。成功・エラー案内をスクロール領域内に表示します。

535件のテスト、ビルド、警告なしlint、実画面と全体ブラウザー回帰を確認。真人、正式機器、原刺激素材の検証は未完了です。
