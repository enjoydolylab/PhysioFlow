# PhysioFlow 0.6.0-beta.17

実験の部品設定と実行時の解釈を一致させました。

- ランダム分岐B/C/Dを空欄にすると既定の重みに戻ります。明示した0は保持します。
- 接続済み分岐の重みの合計が0の場合、実行前にエラーを表示。未接続の分岐は合計に含めません。設定検証と実行で同じ計算を使用します。
- ループ回数、認知課題の時間、明示したランダム重みで、空文字・真偽値・配列の暗黙的な数値変換を拒否します。合法な0や既定のnullは用途に応じて保持します。
- ループの繰り返し条件に数値・真偽値の検証と入力を追加。真偽判定では不要な比較値を隠します。
- 不正なtrial IDは検証エラーとして表示し、検証処理の停止を防止します。

522件のテスト、ビルド、警告なしlint、実編集画面および全体ブラウザー回帰が通過。真人試用、正式機器、原刺激素材の実験結果は未検証です。
