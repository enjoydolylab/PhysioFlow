# PhysioFlow 0.6.0-beta.15

実験編集画面の読みやすさとテンプレート設定の操作性を改善しました。

- インスペクターと一括編集の間隔、選択数、チェック項目、主操作を整理。
- 校正結果に阻断・注意の区別を表示し、深色テーマの文字と入力欄を調整。
- Stroop、Go/No-go、感情実験で設定ダイアログを共通化。短い画面、Tab、Esc、フォーカス復帰に対応。作成中の操作を保護し、保存失敗時は設定を保持。
- モード、部品分類、説明、検索文案の日本語・中国語表示を改善。保存済みの研究内容は維持。
- 条件分岐の数値・真偽期待値を検証し、比較値のバインドに対応。

515件の自動テスト、ビルド、警告なしのlint、実画面の複数サイズ・テーマ・キーボード操作を確認しました。真人試用、正式機器、原刺激素材による実験結果は未検証です。
