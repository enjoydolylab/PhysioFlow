# PhysioFlow v0.6.0-beta.6 — 离线验收候选版

本版补齐古口前辈快照中的媒体与测试运行功能，并闭环不依赖原视频、真实硬件或研究室网络的基本流程。使用明确标记的测试素材和 BrainFlow Synthetic 数据，不能作为正式研究验收。

## 主要改动

- 占位素材导入、按名称/指定条目绑定，保留素材身份；缺失或校验错误阻止冻结和采集。
- 分块哈希与桌面媒体传输、写完后原子替换；播放时仅加载当前页面素材。
- 图片/视频可选全视口等比例展示。
- 测试运行确认退出、保留编辑状态、等待保存队列；清理和最终保存失败可重试。
- 正式运行检查工作目录权限；修复 Hosted 沙箱分组执行快照遗漏。
- PhysioDB 上传超时显示明确提示，并保留已确认/可能写入的批次范围。

## 使用与升级

1. 关闭实验，备份整个数据目录、协议和会话 ZIP 后升级。
2. Windows 使用 x64 安装包（未签名，需 WebView2）；Web ZIP 解压后运行对应启动脚本，需要 Python 3。Web 建议 Chrome/Edge，保持原来的 URL/端口。
3. 选择数据目录，导入协议，上传对应媒体并检查；先测试再冻结正式采集。协议 JSON 不包含视频字节。
4. BrainFlow 代理另行启动，见 tools/brainflow/README.md。实际 PhysioDB 仍需要研究室地址和认证。
5. 回退时使用旧安装包及升级前备份，避免旧版覆盖新会话。

## 验证与限制

445 项测试、生产构建、Lint、三个浏览器回归套件；新增离线浏览器验收覆盖 210 节点、1,080 回答的加速结构运行，真实 Synthetic 代理重启重连及原始记录对照，本地 PhysioDB HTTP 成功、错配、部分失败、取消和超时。Rust 验证分块写入及替换保护。

未验收：原始 40 视频及约 112 分钟实验、真实设备、真实 PhysioDB、Windows 真机安装/DPI及研究人员签收。复杂循环/分支分组随机、未提交内部进度和多文件事务仍有原有范围限制。详见 docs/OFFLINE_ACCEPTANCE_2026-09-24.md；机器记录在 artifacts/offline-acceptance-2026-09-24/。
