# PhysioFlow beta.24：テンプレートと設定の編集

## テンプレートから作成

プロジェクト一覧でテンプレートを開きます。Stroop の試行数は4～64の4の倍数、Go/No-Goは10～100の10の倍数です。作成前に本試行・練習試行の件数を確認します。Go/No-Goの件数は整数に丸めるため、指定割合と実際の割合が少し異なる場合があります。画面には実際の Go / No-Go 件数を表示します。

感情テンプレートでは注視時間、回復時間、条件順序、乱数シードを設定できます。5条件のSAMと感情ラベルの質問を含みます。各条件の動画は別途追加してください。テンプレートを作成しただけでは映像付き実験の準備は完了しません。

入力に問題がある場合は案内に従って修正します。保存に失敗した場合は入力を保持したままエラーを表示します。保存先を確認してから再試行してください。

## 検証の問題から設定へ移動

インスペクタの検証一覧で問題を選ぶと、対象ノードまたは接続を選択します。以前の接続や複数選択は解除されます。グループの問題は入口ノードへ移動できます。

「選択中の項目の問題のみ表示」を使うと、現在の項目に関係する問題だけを表示します。全体を確認する場合はチェックを外してください。対象を選択していない場合の「問題なし」は、実験全体に問題がないという意味ではありません。全体のブロック件数も確認してください。

## 数値を編集して保存

時長や数値欄を空にしても0には変換しません。待機時間や固定時間が空の場合、実行前の設定検証で修正を求めます。0 ms を指定したい場合は明示的に0を入力してください。

設定を保存し、再度開いて値を確認します。実行前に設計を確定し、素材や設定の不足を修正してください。正式な素材と機器での実験結果、実際の利用者による試用結果はまだありません。

問題のノードを選択すると、フロー図の画面中央へ移動します。長い設計でも対象ノードの場所を確認できます。

## グループ内の一括変更

適用先を選び、件数を確認してから適用します。種類タグのない質問票は、適用先を明示的に選ぶ必要があります。各批次は個別に元に戻す/やり直す操作ができます。元に戻した後で新しく編集すると、以前のやり直し記録は破棄します。質問ID、各試行の素材や時間設定は保持します。

## テンプレート設定と操作

設定画面は共通のダイアログです。Tabで入力欄を移動し、Escで閉じると開始ボタンに戻ります。作成中は入力と閉じる操作を保護します。保存に失敗した場合は設定を保持します。

条件分岐の数値比較では期待値が必要です。0と負数も使用できます。真偽判定では期待値は不要です。比較値を変数またはポートから取得する場合、固定の期待値は使用しません。校正カードの対象ノードへ移動して修正してください。
# beta.24 分岐とループ設定

ランダム分岐のB/C/Dは空欄で既定値を使用します。Bの既定値は1−Aです。0を入力するとその分岐の重みは0になります。接続済み分岐の重みの合計は0より大きい必要があります。

ループは最大回数と繰り返し条件を設定できます。until変数を接続した場合、その条件が成立する間は本体を繰り返し、不成立になると終了します。最大回数にも従います。数字の比較値は空欄にできません。真偽判定には比較値は不要です。until入力がない場合、条件は使用しません。
# beta.24 参加者画面の回答確認

数字入力はMin/Maxで上下限を設定できます。空欄は未設定です。下限と上限が逆の場合、Screen checksから入力欄へ移動して修正できます。

画面のPreviewを開き「回答を試す」を選ぶと、必須や範囲の検証、提出値を確認できます。入力を変えると前の提出結果は消えます。「回答をリセット」で最初から確認できます。実験や記録保存は開始しません。動的な進捗、機器、画面遷移や実際の刺激タイミングの確認には別途テスト実行が必要です。
# beta.24 単一選択入力

参加者画面でInputを選び、Input typeをSingle choiceに変更します。Add response optionで選択肢を追加し、表示文字と記録値を設定します。記録値は固有の文字列です。"0"も使用できます。未選択は空欄です。

表示文字と記録値の不足や重複はScreen checksから修正できます。Previewの「回答を試す」で必須回答と提出値を確認してください。実験記録では表示文字ではなく記録値が回答になります。選択肢の表示文字は保存された実験手順から追跡できます。
# beta.24 複数選択入力

Input typeでMultiple choiceを選び、選択肢の表示文字と記録値を設定します。Requiredの場合は最低1項目の選択が必要です。任意で何も選択しなかった回答は[]になります。

回答には表示文字ではなく記録値の文字列配列が保存されます。順序はクリック順ではなく、選択肢の設定順です。"0"も選択肢の値に使用できます。Previewの「回答を試す」で複数選択・解除・提出値を確認してください。
# beta.24 入力部品の直接追加

部品ライブラリーのFormから数値入力、単一選択、複数選択を直接追加できます。クリック、Tabで移動してEnter、キャンバスへのドラッグ、レイヤーツリーへのドラッグに対応します。

単一/複数選択は2つの仮の選択肢から始まります。実験の表示文字と記録値へ変更してください。新しい入力の回答名は既存の入力と重複しないように生成されます。配置や設定は元に戻す/やり直しで確認できます。
# beta.24 回答フィールドと設定の確認

参加者画面の下にある「回答フィールド」を開くと、入力名、型、必須/任意と選択肢の記録値を確認できます。「設定」でその入力の回答名へ移動します。プレビューからでも編集へ戻れます。

回答名の空欄や重複はScreen checksに表示されます。修正後も他の範囲・選択肢の問題が残っていないか確認してください。回答名と記録値は表示言語を切り替えても原文を維持します。

この一覧は画面内の入力を対象とします。ボタンのsetVariableなどが追加する値を含む完全な実行データ契約ではありません。必要な追加出力はテスト実行の記録で確認してください。
# beta.24 画面テンプレートの再利用

画面設計器のPresetsを開き「画面テンプレートを書き出す」を選びます。有効な画面設定がPhysioFlow-screen.participant-ui.jsonとして保存されます。「画面テンプレートを読み込む」から5 MB以内のJSONを選び、置き換えを確認します。元に戻す/やり直しを利用できます。

テーマ、入力、選択肢、動作、変数接続と固定サイズを再利用します。メディアファイルや実験変数の定義は別途準備してください。サイズ未指定の画面は現在の画布サイズになります。読み込み後の案内で寸法を確認してください。

読み込み中に編集した場合やツールを閉じた場合、古い読み込みは適用されません。再利用した画面のメディア・変数接続を確認し、Previewの「回答を試す」とテスト実行で確認してから使用してください。
