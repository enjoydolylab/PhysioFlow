日期：2026-10-09，Asia/Tokyo。阶段：本轮主流程和UI重构已完成，逐项证据见 [完整验收](PF_REFACTOR_ACCEPTANCE_2026-10-09.md)。下方分轮内容保留实施过程；早期“下一轮”不是当前待办。

## 已确认基础

用户确认实机验证及前辈系统验证已完成，直接复用相关代码。硬件基础验证不再作为前置待办；仍需验证接入 PF 后的时间对齐、会话关联、保存和回读，不将前辈系统验证等同于所有 PF 新流程验收。

## 源码分析

- App.jsx 分别管理 home/builder/setup/runner/analytics；Dashboard 内还有 projects/sessions/tools 切换，同时 SessionManager 是独立大弹层。
- 数据入口分散为 Dashboard 会话、SessionManager、Analytics、DataPanel 和 /admin PhysioDB 分析；旧 BioDB 与新 PhysioDB 在部分主操作中并存。
- 准备逻辑分散为 PreRunChecklist、GraphSessionSetup、GraphRuntimeRunnerPage 的 ready 页。参与者、存储、媒体、设备、DB 认证需跨页面检查。
- Composer 顶部同时提供四种模式、撤销/重做、Preview、Freeze、BioDB、Export、Save、返回；默认视觉层级没有清楚区分主次。
- 首页大标题和统计占据操作空间；完成/详情页仍包含大量文件、技术状态和零值统计，关键结论容易被埋没。
- /operator 已有独立窗口，但与本地准备流程仍需要统一角色和上下文；BroadcastChannel 当前仅支持同源同浏览器，设计不假定已实现跨电脑控制。

## 推荐产品结构

导航统一为“实验项目 / 实验记录 / 设备与连接 / 设置”。数据库管理归设备与连接，数据查看和分析归记录详情，不把独立实验台作为必经入口。

项目内流程：设计 → 测试 / 正式准备 → 运行 → 结果。正式准备统一在管理员画面完成；参与者画面仅等待、说明、刺激、回答、暂停、结束。

- 项目页：近期项目、继续上次、开始实验；以紧凑列表为主，版本和详情按需展开。
- 设计页：上方任务栏，中间执行步骤，右侧当前步骤设置；常见直线实验默认用顺序视图，分支/循环可切换图模式，使用同一协议模型。
- 准备页：参与者与语言、设备/信号、数据保存三组；媒体和权限后台预检，异常就地处理，只保留一个“开始”按钮。
- 运行页：管理员显示当前阶段、信号、录制与同步及暂停/停止；参与者无工具栏。数据链路异常与信号异常分别呈现，是否暂停由实验规则明确决定。
- 结果页：优先显示实验结果、数据保存情况、质量问题。默认按刺激/阶段定位波形，统计与导出在同一上下文；技术文件和 IDs 折叠。
- 连接：一次配置，运行时选择已验证设备/数据库目标，避免每次输入 API key 和 ID。测试与正式模式明确区分，离线不能伪装成数据库验证通过。

测试记录的长远结构建议归专用测试研究，按运行建立测试实验/会话，避免每次堆积 research；这是目标设计，当前实现仍每次创建隔离 research，改动需确保权限和隔离。

## 风格选项

A 推荐：暖白专业工具。暖白背景、深灰文字、克制的森林绿，平整分区、小圆角、轻阴影；用于项目、设计、准备和结果。参考现有 PF 配色延续辨识度，移除大宣传文案、渐变和重复卡片。

B：中性实验控制台。灰白背景、蓝色主操作、紧凑表格、明显状态，适合设备与运行监控；可与 A 统一字号和间距。

C：高密度科研工作站。灰黑、中性图表、多面板和更多可见参数，适合高级调试；不适合作为日常默认界面。

推荐 A 为全局、B 的信息组织用于运行监控。深色主题可选，参与者刺激背景由实验方案决定，不随管理员主题自动改变。

视觉约束：正文 14–16px，8px 间距体系，6–10px 圆角；绿色表示正常/主操作，琥珀表示待处理，红色表示中断或失败；状态必须有文字，不能仅靠颜色。图表通道颜色固定，不能与故障颜色含义混淆。中日英布局使用同一组件结构与完整字符串翻译。

## 重构顺序和验收

1. 信息架构与设计规范；先做项目、准备、结果三页的可审核布局，不先改硬件逻辑。
2. 统一导航和记录页，接入已有 SDK、验证报告和分析能力。
3. 编辑器顺序/图双视图，收敛工具栏与设置；旧协议保持可读取与运行。
4. 管理员准备、设备检查和双屏运行统一，复用前辈已验证代码。
5. 统一保存、离线/待上传/核对/一致/异常状态，清理旧入口与旧样式。

验收任务：从项目页启动已有实验；只在一个管理员准备页完成检查；参与者流程无配置步骤；结束后同一记录内能确认保存、查看信号与事件、导出。既有数据和协议不丢失，数据库异常不误报成功，浅色/深色及三语均可读。
