# PhysioFlow 0.6.0-beta.26

参加者画面編集の保存・終了フローを改善しました。

- 入力欄でもCtrl+S / Cmd+Sで保存。全画面編集に保存ボタンと保存状態を追加しました。
- 連続保存は順番に書き込み、保存中に追加した編集を古い内容で上書きしません。新しい変更があれば未保存のまま保持します。
- 終了時に保存・破棄・キャンセルを選べます。保存失敗時は編集を保持し、保存中に終了を取り消しても画面が勝手に移動しません。
- 書き込み失敗からの再試行、375/1280幅での操作、535テスト、ビルド、警告なしlintと全体ブラウザー回帰を確認しました。

実際の利用者、正式機器、原刺激素材による検証は未完了です。
