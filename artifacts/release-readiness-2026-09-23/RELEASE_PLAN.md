涉及 src/GraphRuntimeRunnerPage.jsx、src/runtime/runtimeMachine.js、运行模式创建入口与恢复存储；旧版 RuntimeRunnerPage.jsx 如仍对外提供 Test Run，需同步覆盖。

2. 在每次可展示节点进入时保存访问快照：currentNodeId、variables、outputs、loopCounts/loopStack、随机状态、刺激分配、完成/跳过历史及该访问答案。保存的是实际访问序列，不能按 graph.nodes 数组索引回退。
3. 返回时停止当前计时器、媒体和待处理提交；使旧回调失效，再恢复上一次展示快照。增加 presentation/visit 标识以强制重新挂载组件；上一页计时从零开始，已填答案可预填修改。
4. 日志追加 test_navigation_back 和新展示事件；事件序号保持递增。已发生的设备 marker 和原始采样不能回滚。旧访问标记 superseded，分析排除其有效答案，原始审计记录保留。
5. 当前页返回后再次向前时重新计算分支，清除旧的向前历史；保留刺激快照及随机状态，避免返回消耗一个新刺激。循环必须恢复到对应的第几次访问。
6. 历史写入恢复 checkpoint；无历史的旧 checkpoint 禁用返回。第一展示页禁用。完成页返回不纳入首版，避免改写已保存 session。
7. 按钮放在测试操作区，遵守实验界面顶部菜单默认隐藏的要求。

5. 实际网页点 Export，验证通知与下载文件；重新导入该文件比较协议内容、版本、分组、随机配置、资源引用，确认无 token。JSON 不包含视频本体，交付说明须写明资源迁移方法。
