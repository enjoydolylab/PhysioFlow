- Graph 测试运行支持返回上一页；保留原始事件和回答，标记被替代访问，分析和回放识别回退。
- Protocol 导出后显示生成及发起下载通知。浏览器下载接口不能证明磁盘写入完成，提示不作此承诺。
- SAM 增加 dominance 及图像量表，修复桌面九档排列。新增SAM三维同屏和Likert矩阵，修复窄屏表格溢出，编辑器提示不兼容布局。
- 媒体编辑预览按当前节点及其池/嵌套媒体加载，支持统一工作目录读取并清理异步资源。
- 修复循环完成/尝试次数显示；冻结版本入口明确为正式采集准备；准备页补齐目录错误对话框。
- 媒体池支持类别前后半场平衡，异常配置提前拦截，准备页按模式说明分配规则。
- 组内等待时长、问卷与媒体展示批量应用，保留目标身份及媒体来源。
- 版本历史可查看旧版；单版移入可恢复区、恢复；历史版本派生按项目最高编号递增。
- Graph 冻结控件禁用；旧版解冻入口改为创建独立草稿；修复旧版菜单与会话管理关闭按钮遮挡。

- OpenBCI/Mybeat真实设备未验收；synthetic验证不能替代真实通道、采样率、单位和同步精度。
