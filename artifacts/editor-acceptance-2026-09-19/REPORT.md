# 编辑器数据字段与配置边界验收 · 2026-09-19

本轮实际操作 http://127.0.0.1:5187 的 QA editor data fields 项目。已有文档及其他项目未覆盖；代码仍在工作区，未提交或部署。

## 修复

- 连续添加Input、复制输入框或含输入框的容器时，原先会重复使用响应名，导致多个框共用同一个答案。新增/拖入、复制、粘贴现在为新增字段自动选择未使用名称；多选复制检查当前已插入结果，避免复制之间冲突。源元素配置不变。
- 手动配置或JSON导入的重复响应名现在产生校验错误。嵌套容器也参与唯一性检查，避免悄悄覆盖数据。
- 按钮评分1.5–7原先显示“有效”，但生成1.5、2.5…6.5，无法选到最大值。现在要求递增整数界限，并最多1000个按钮选项。输入0仍有效。大范围连续数值应使用数字输入或滑条。
- 普通评分及问卷离散量表预览不再直接按任意上限分配数组。问卷保留原有最多21个离散选项规则，非法草稿显示提示而不生成巨大按钮数组。

## 实际网页证据

| 检查 | 结果 |
|---|---|
| 两次新增Input | 修复前均为response且schema valid；修复后已有重名显示错误（01） |
| 新增和复制 | 自动得到response_2与response_2_2（02） |
| 四框独立填写 | first answer、第二个答案、第三回答、copied field answer互不影响（03） |
| 完整会话导出 | 4条响应各自保存，按字段名逐项比对成功，见response-verification.json及QA-UNIQUE-FIELDS_session_bundle.zip |
| 非法JSON | Apply显示行列位置语法错误，不修改原协议（05） |
| JSON重名输入 | Apply显示具体字段路径并拒绝（06） |
| 合法JSON | 格式化、应用、保存、退出重开，描述与四个字段名保持一致（07） |
| 小数评分界限 | 编辑器显示阻塞错误（08） |
| 10亿上限 | 页面仍可操作，显示范围错误，没有生成大量按钮（09） |
| 恢复有效评分 | 0–2重新显示0、1、2；Graph valid，项目保存成功 |
