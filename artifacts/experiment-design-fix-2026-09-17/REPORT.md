# 实验设计修复与网页验证记录（2026-09-17）

代码已修复并在本地真实网页操作验证。验证地址为 http://127.0.0.1:5187。以下区分手动网页操作、自动回归和未验证范围；不将通过测试等同于所有设备及所有配置均可正式采集。

## 修复内容

1. 嵌套循环：循环次数按本次进入计算，2×3 正确执行六次；暂停、刷新恢复及回放保留每次访问。
2. Response：首次按键立即锁定；反馈和手动确认期间不再被响应超时覆盖。
3. 反应时：保留响应采集时的 RT，另外记录节点停留时间；遗漏的 RT 为 null；认知任务保留各 trial 的 RT。
4. 图连接：同一控制输出口的多条连线在编辑、导入校验和冻结阶段被拦截。
5. BIDS：events.tsv 与 participants.tsv 使用真正的制表符、缺失值 n/a，并处理字段内的换行及分隔符。
6. 会话导出：Graph 协议通过对应导出器生成完整包和简化包，修复旧 blocks.flatMap 路径崩溃。
7. 回放：重复节点访问不再去重；仅应用运行时接受的变量更新，避免原始响应字段污染变量。
8. 冻结：按钮和键盘 Undo/Redo 都不能撤销冻结状态来解锁协议。
9. Attention：反馈阶段暂停后可以恢复、提交；响应阶段暂停保留剩余时限并排除暂停的反应时。
10. 校准：修正物理宽高字段；使用 CSS 屏幕像素，避免 Retina 的 DPR 再次放大刺激。
11. Go/No-Go：误按 commission 不再同时计入 omission。
12. 循环下进度按唯一节点覆盖计算，避免重复访问造成百分比超过 100%。
